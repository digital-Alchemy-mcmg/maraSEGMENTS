# Segment B Ontology

Primary objects: A_ENVELOPE, B_SIDECAR, CANDIDATE_VAULT, TARGET_REQUIREMENT, COMPETENCY_NODE, EVIDENCE_BINDING, AUDIT_RECORD, VERIFIED_PROPOSITION, TRACE_RECEIPT, SEALED_B_ENVELOPE, GATE_B_RECEIPT, B_AUDIT_REPORT.

Target authority and candidate authority remain distinct. B creates no evidence. Unresolved target requirements never become candidate claims. Every C-visible proposition resolves through B4 -> B3 -> B2 lineage.
