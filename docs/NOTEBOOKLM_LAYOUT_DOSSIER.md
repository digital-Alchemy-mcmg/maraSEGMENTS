## Role in Segment C

This NotebookLM notebook is the authoritative dossier carrying the complete résumé-layout set used by Segment C.

It is registered here as a source reference for:

- C3 — document/layout projection decisions;
- C4 — layout validation, density, geometry, fit, and rework checks;
- C5 — render selection and provenance binding for the chosen surface.

The dossier is a source reference, not a runtime fallback. Segment C must not invent or substitute a layout when a required layout definition is absent from the authorized source material.

## Provenance Rule

Any layout selected or rendered by Segment C should be traceable to:

1. the Segment C traveling envelope and authorized content;
2. the selected layout identifier;
3. this NotebookLM dossier or a repository-normalized derivative explicitly tied back to it;
4. the C4 validation record;
5. the C5 artifact/provenance receipt.

No layout data is embedded here beyond the source reference. This file intentionally avoids reproducing or fabricating dossier contents.
